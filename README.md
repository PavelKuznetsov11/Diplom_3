# Stellar Burgers UI Tests

Проект с UI-автотестами для web-приложения Stellar Burgers.

Цель проекта — проверить основные пользовательские сценарии через интерфейс приложения: регистрацию, авторизацию, переходы между разделами, личный кабинет и оформление заказа.

## Что тестируется

- регистрация пользователя
- авторизация пользователя
- выход из аккаунта
- переход в личный кабинет
- переход из личного кабинета на главную страницу
- переходы между разделами конструктора
- оформление заказа
- отображение ключевых элементов интерфейса

## Технологии

- Python
- Selenium WebDriver
- Pytest
- Allure
- Page Object Model
- Git

## Что проверяют тесты

- корректность работы UI
- основные пользовательские сценарии
- отображение элементов интерфейса
- переходы между страницами

Page Object Model
В проекте используется паттерн Page Object Model.
Логика взаимодействия со страницами вынесена в отдельные классы, а локаторы элементов — в отдельный слой.
Такой подход делает автотесты более читаемыми и упрощает поддержку проекта при изменениях в интерфейсе.

Как запустить проект

Клонировать репозиторий:
git clone https://github.com/PavelKuznetsov11/ui-tests-stellar-burgers.git

Перейти в папку проекта:
cd ui-tests-stellar-burgers

Создать виртуальное окружение:
python -m venv venv
Активировать виртуальное окружение.

Для Windows:
venv\Scripts\activate

Для macOS / Linux:
source venv/bin/activate

Установить зависимости:
pip install -r requirements.txt

Запустить тесты:
pytest -v

Запустить тесты с генерацией Allure-результатов:
pytest --alluredir=allure_results

Открыть Allure-отчёт:
allure serve allure_results
